# Contributor Code of Conduct

## Our Pledge

We are committed to building a welcoming, respectful, and professional community for everyone contributing to and using this project.

We do not tolerate harassment, discrimination, or abusive behavior in any project space.

## Scope

This Code of Conduct applies to all project channels, including:

- GitHub issues, discussions, and pull requests
- Project reviews and code feedback
- Community chat or collaboration spaces associated with this project
- Events or presentations in which this project is represented

## Expected Behavior

- Be respectful, civil, and inclusive in all interactions.
- Assume good intentions and focus feedback on ideas and code, not people.
- Keep language and communication professional.
- Help maintain a safe environment by reporting abusive behavior.
- Respect different backgrounds, identities, and perspectives.

## Unacceptable Behavior

- Harassment, hate, discriminatory remarks, or personal attacks
- Intimidation, threats, or targeted hostility
- Public or private sharing of private or identifying information without consent
- Sexual or discriminatory imagery, unwelcome advances, or harassment
- Disruptive spam, trolling, or manipulative off-topic behavior

## Reporting

If you experience or witness a code-of-conduct violation, report it in a GitHub issue or discussion with concise details.  
For sensitive situations, use GitHub’s private reporting mechanisms (or the repository’s moderation path if provided).

## Enforcement

Project maintainers may take any action they deem appropriate, including:

- Warning or temporary pause from participation
- Removal of comments or content
- Temporary or permanent access restriction

This policy is intended to be applied consistently and fairly, balancing safety with constructive participation.
