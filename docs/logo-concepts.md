# mentiko logo concept

## mark

core shape:
  three interconnected nodes forming a subtle "C" arc
  each node is a hexagon with rounded corners
  nodes connected by clean horizontal lines
  overall form suggests forward momentum (left to right)

geometry:
  node 1:  full hexagon, positioned left
  node 2:  full hexagon, center
  node 3:  split hexagon (right side open), positioned right
           the opening creates a ">" arrow implication

  connection: solid lines between nodes, not touching
              negative space between elements

meaning:
  nodes = autonomous agents
  connections = chaining/coordination
  arrow shape = forward progress, output
  three nodes = minimum to form a "chain"

## color

primary:   #0a8afc (electric blue)
secondary: #6366f1 (indigo accent)
dark mode: #0a8afc on #0f0f0f
light mode: #0066cc on #ffffff

gradient option:
  left node:  electric blue
  center:     blue-indigo transition
  right node: indigo (implies transformation)

## typography

wordmark: "mentiko"
font:     inter, geist mono, or similar geometric sans
weight:   600 (semibold)
spacing:  slightly tracked out (+3%)
styling:  lowercase "agent", camel "chain" or all lowercase

alignment:
  mark left, wordmark right
  or stacked for square formats

## variants

icon only:        the 3-node mark for favicons, app icons
horizontal:       mark + wordmark side by side
stacked:          mark above, "agent" then "chain" below
monogram:         "ac" with chain underline for tiny sizes

## scalability

16px:    nodes become squares with connecting line
32px:    full detail visible
512px+:  subtle gradients, optional depth

## what it represents

agents acting in sequence
outputs flowing forward
distributed coordination
clean, predictable automation

## anti-patterns avoided

no literal chain links (too industrial/old-school)
no robot icons (cliche, dates quickly)
no complex gradients (won't scale)
no drop shadows (breaks in flat contexts)

## tagline integration

"mentiko" mark [agent workflows, not tasks]

## concept 02: "forward flow"

### core mark

three ascending right-pointing elements forming a greater-than cascade

```
┌─┐   ┌─┐   ┌─┐
│ ╲  │ ╲  │ ╲
└──┐ └──┐ └──┐
   ╲    ╲    ╲
    ╲    ╲    ╲
     ▼    ▼    ▼
```

simplified:
```
▷   ▷▷   ▷▷▷
```

each shape is a 60-degree wedge (not a triangle - open on the left)
graduating sizes: small → medium → large
negative space between them creates rhythm

### meaning

- terminal prompt heritage (the > character)
- sequential agent handoffs
- momentum, forward progress
- chaining without literal chain imagery
- three represents: input → process → output

### color system

primary:   #0F172A (slate-950) - near black, depth
accent:    #6366F1 (indigo-500) - tech purple-blue
highlight: #22D3EE (cyan-400) - electric cyan

dark mode:
  marks: accent → accent-lighter → highlight gradient
  text: #F8FAFC (slate-50)

light mode:
  marks: primary → accent-600 → accent-500
  text: #0F172A

### typography

wordmark: "mentiko" in a custom modified geometric sans
          agent: lowercase, light weight (300)
          -: medium weight (500), slightly elongated
          chain: lowercase, medium weight (500)

letterforms: almost monospace but not actually
            consistent stroke widths
            slightly squared terminals for tech feel

### lockup variations

horizontal:
  ▷▷▷  mentiko

stacked:
  ▷▷▷
  mentiko

icon only:
  ▷▷▷

### scalability

- 16x16 favicon: single ▷ in accent color
- 32x32: two wedges ▷▷
- 64+: full three-wedge mark

### animations (optional, for web)

- sequential cascade: wedge 1 fades in, then 2, then 3
- pulse effect: subtle glow on hover
- "data flow" animation: small particles flow through the gaps

### why this works

- no chain imagery, distinct from node-link diagrams
- terminal prompt heritage fits developer tool audience
- ascending wedges imply improvement, progress
- three elements match the brand name syllable count
- geometric = reproducible at any size
- negative space gives it breathing room, feels modern

# concept 3: the velocity brackets

## mark

core shape:
  four terminal-inspired brackets in a forward-cascading sequence
  represents the chain of execution: one agent passing to the next

  [   >   ]   >

reading left to right:
  [ = initiate, spawn, start agent
  > = forward, pass to next agent
  ] = complete, wrap up, return
  > = continue the chain

the four elements are positioned with decreasing spacing
to suggest acceleration:

  [ >    ]  >

gaps compress (32px, 16px, 8px) to visually communicate speed

## motion effects (static but dynamic)

1. trailing edges have subtle opacity gradients
   - right edge of each bracket fades 100% to 60%
   - creates "speed trail" effect

2. slight skew (3 degrees) on all elements
   - forward lean, aggressive italic
   - suggests forward velocity

3. final > has double-shadow effect
   - two layered versions offset by 2px, 4px
   - like a motion blur capture

## color

dark mode (primary):
  brackets:  #00E5FF (cyan-400) - terminal green energy
  arrows:   #FFD600 (yellow-400) - command prompt gold
  gradient: cyan to yellow across the sequence
  glow:     box-shadow 0 0 8px rgba(0,229,255,0.5)

light mode:
  brackets:  #00B8CC (cyan-600) - deeper for contrast
  arrows:   #FFA000 (amber-600) - grounded gold
  no glow, solid shapes

accent (marketing/splash):
  purple-pink gradient #D500F9 to #FF4081

## typography

wordmark: "mentiko"
font:     monospace (JetBrains Mono, Fira Code, or custom geo mono)
weight:   "agent" in regular, "-chain" in light
spacing:  no space, hyphen is part of design

alignment:
  wordmark sits below icon, left-aligned with first bracket
  optical alignment - connected but not touching

## scalability

16x16 favicon:
  - reduces to [>] (two shapes only)
  - open bracket + single arrow

32x32:
  - [ > ] (three shapes)
  - enough to read the sequence

64+:
  - full four-shape cascade with all details
  - shadows, gradients, proper spacing

## what it represents

the cascade = sequential execution, one triggering the next

not a chain (overused literal), not letters "ac" (boring),
but the concept itself: flow, execution, propagation.
feels like a command that runs and triggers the next command.

## memorability factors

- four elements = easy to remember (cognitive chunking)
- left-to-right story = natural reading direction
- bracket familiarity = every dev recognizes [ and >
- asymmetry = more interesting than symmetric logos
- decreasing spacing = subconsciously communicates "fast"

## variants

stacked version:
  [ > ] >
  mentiko

horizontal:
  [ > ] >  mentiko (inline)

mark-only:
  just the icon, no wordmark

## uniqueness check

avoided:
  - literal chains (everyone does this)
  - letters "AC" or "a" or "c"
  - network nodes/dots (generic tech)
  - circles (overused)

done instead:
  - code symbols - actual terminal syntax
  - motion through opacity and spacing
  - forward lean for velocity
  - cascade for the "chain" concept (abstract)
  - tells a story left-to-right

## usage scenarios

terminal:  [ > ] > in cyan with glow, looks like prompt
github:    dark mode avatar, subtle glow
swag:      embossed, motion blur effect in depth
app icon:  full gradient with glow, pops on dock

## why this works

- devs recognize [ and > immediately
- not another generic tech logo with dots and lines
- tells the story: spawn -> forward -> complete -> continue
- works at 16px and at billboard size
- no cultural flags or symbols that age poorly
- pure, functional, aesthetic
